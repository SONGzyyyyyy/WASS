## Dataset

This project uses the publicly available **WiSig dataset**, a large-scale WiFi signal dataset designed for receiver- and channel-agnostic radio frequency fingerprinting (RFF).

The dataset is described in:

> S. Hanna, S. Karunaratne, and D. Cabric, “WiSig: A Large-Scale WiFi Signal Dataset for Receiver and Channel Agnostic RF Fingerprinting,” *IEEE Access*, vol. 10, pp. 22808–22818, 2022.
